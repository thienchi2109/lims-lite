# Vietnamese Localization Dictionary

## Roles
- Analyst: Kiểm nghiệm viên
- Manager: Quản lý
- Admin: Quản trị viên

## Entities
- Sample: Mẫu
- Accession: Tiếp nhận mẫu
- Test / Assay: Chỉ tiêu / Xét nghiệm
- Result: Kết quả
- Client: Khách hàng
- Batch: Lô

## Statuses
- Pending: Chờ xử lý
- Received: Đã nhận
- Assigned: Đã giao
- In Progress: Đang thực hiện
- Completed: Hoàn thành
- Reviewed: Đã duyệt
- Rejected: Từ chối

## Actions
- Login: Đăng nhập
- Logout: Đăng xuất
- Submit: Gửi
- Save: Lưu
- Cancel: Hủy
- Edit: Sửa
- Delete: Xóa
- View: Xem
- Search: Tìm kiếm
- Filter: Lọc
- Assign: Chỉ định
- Scan QR: Quét QR

## UI Elements
- Dashboard: Bảng điều khiển
- Settings: Cài đặt
- Profile: Hồ sơ
- Notifications: Thông báo

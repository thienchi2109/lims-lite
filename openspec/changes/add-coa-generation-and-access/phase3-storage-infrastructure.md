## Storage Path Structure

### Path Convention

```
coa-reports/
└── {sample_id}/
    ├── 1-2025-12-14T08:30:00.000Z.html    # Version 1 (original)
    ├── 2-2025-12-15T14:22:00.000Z.html    # Version 2 (amendment)
    └── 3-2025-12-16T09:15:00.000Z.html    # Version 3 (amendment)
```

**Path Format:** `{sample_id}/{version}-{iso-timestamp}.html`

**Components:**
- `{sample_id}` - UUID of the sample (creates folder structure)
- `{version}` - Integer version number (1, 2, 3, ...)
- `{iso-timestamp}` - ISO 8601 timestamp of generation (e.g., `2025-12-14T08:30:00.000Z`)
- `.html` - File extension

**Examples:**
```
coa-reports/a1b2c3d4-e5f6-7890-abcd-ef1234567890/1-2025-12-14T08:30:00.000Z.html
coa-reports/f9e8d7c6-b5a4-3210-fedc-ba9876543210/1-2025-12-15T10:15:00.000Z.html
coa-reports/a1b2c3d4-e5f6-7890-abcd-ef1234567890/2-2025-12-16T09:00:00.000Z.html
```

**Benefits:**
- ✅ Folder structure by sample ID prevents path collisions
- ✅ Version number in filename enables quick identification
- ✅ ISO timestamp provides sortability and audit trail
- ✅ Extension validation enforces HTML-only uploads

## RLS Policies

### Policy Matrix

| Policy Name | Operation | Role | Condition | Purpose |
|-------------|-----------|------|-----------|---------|
| `coa_storage_insert_authenticated` | INSERT | authenticated | `bucket_id = 'coa-reports'` AND `get_user_role() IN ('analyst', 'manager')` AND folder structure exists | Staff can upload CoA HTML files |
| `coa_storage_select_authenticated` | SELECT | authenticated | `bucket_id = 'coa-reports'` AND `get_user_role() IN ('analyst', 'manager')` | Staff can read all CoA files |
| *(No UPDATE policy)* | UPDATE | - | Denied by default | CoA files are immutable |
| *(No DELETE policy)* | DELETE | - | Denied by default | Use soft delete in database instead |

### Policy Details

#### 1. INSERT Policy: `coa_storage_insert_authenticated`

**Purpose:** Allow authenticated analysts and managers to upload CoA HTML files with folder structure validation.

**SQL:**
```sql
CREATE POLICY "coa_storage_insert_authenticated"
ON storage.objects FOR INSERT
TO authenticated
WITH CHECK (
    bucket_id = 'coa-reports'
    AND public.get_user_role() IN ('analyst', 'manager')
    AND (storage.foldername(name))[1] IS NOT NULL  -- Ensure folder structure
);
```

**Conditions:**
- `bucket_id = 'coa-reports'` - Only applies to coa-reports bucket
- `get_user_role() IN ('analyst', 'manager')` - Only staff with analyst or manager role
- `(storage.foldername(name))[1] IS NOT NULL` - Ensures file path includes folder (e.g., `{sample_id}/filename.html`)

**Validation:**
```sql
-- Allowed (has folder structure):
-- Path: "a1b2c3d4-e5f6-7890-abcd-ef1234567890/1-2025-12-14T08:30:00.000Z.html"

-- Denied (no folder structure):
-- Path: "1-2025-12-14T08:30:00.000Z.html"
```

#### 2. SELECT Policy: `coa_storage_select_authenticated`

**Purpose:** Allow authenticated analysts and managers to read all CoA files.

**SQL:**
```sql
CREATE POLICY "coa_storage_select_authenticated"
ON storage.objects FOR SELECT
TO authenticated
USING (
    bucket_id = 'coa-reports'
    AND public.get_user_role() IN ('analyst', 'manager')
);
```

**Conditions:**
- `bucket_id = 'coa-reports'` - Only applies to coa-reports bucket
- `get_user_role() IN ('analyst', 'manager')` - Only staff with analyst or manager role

**Note:** Public clients access files via signed URLs, which bypass RLS and use signature validation instead.

#### 3. UPDATE and DELETE - Denied by Default

**Rationale:**
- Certificate of Analysis files are **immutable** once generated (21 CFR Part 11 requirement)
- Amendments create **new versions** rather than modifying existing files
- Soft delete is implemented via `deleted_at` timestamp in `coa_reports` table
- Storage files remain accessible for compliance audits even after soft delete

**Enforcement:**
- No UPDATE policy = all UPDATE operations denied
- No DELETE policy = all DELETE operations denied
- Attempting UPDATE or DELETE will result in RLS violation error

## Signed URL Access for Public Clients

### How Signed URLs Work

**Signed URLs** provide temporary, secure access to private storage objects without requiring authentication.

**Flow:**
```
1. Client authenticates via /api/coa/authenticate (phone + passcode)
2. Server generates JWT token with client_id + sample_id + expiry
3. Client requests download via /api/coa/download?sample_id={id}&token={jwt}
4. Server validates JWT, fetches coa_reports record
5. Server generates signed URL via Supabase Storage API
6. Server logs access to coa_access_log
7. Client redirects to signed URL (1-hour expiry)
8. Supabase Storage validates signature and serves HTML file
```

**Signed URL Properties:**
- **Generated by:** Server action using service role (bypasses RLS)
- **Expiry:** 1 hour (3600 seconds)
- **Signature:** HMAC signature prevents tampering
- **Token binding:** JWT includes client_id + sample_id to prevent sharing
- **Single use:** Consider adding nonce for one-time use (future enhancement)

**Example Code (Server Action):**
```typescript
// src/app/actions/coa.ts
import { createClient } from '@/lib/supabase/server'

export async function generateCoADownloadUrl(sampleId: string, token: string) {
  // Validate JWT token
  const { client_id, sample_id } = verifyJWT(token);
  if (sample_id !== sampleId) throw new Error('Invalid token');

  // Fetch CoA report record
  const supabase = await createClient()
  const { data: coa, error } = await supabase
    .from('coa_reports')
    .select('file_path, file_hash')
    .eq('sample_id', sampleId)
    .eq('status', 'ready')
    .order('version', { ascending: false })
    .limit(1)
    .single()

  if (error || !coa) throw new Error('CoA not found');

  // Generate signed URL (1 hour expiry)
  const { data: signedUrl } = await supabase
    .storage
    .from('coa-reports')
    .createSignedUrl(coa.file_path, 3600)  // 3600 seconds = 1 hour

  // Log access
  await supabase.from('coa_access_log').insert({
    client_id,
    sample_id: sampleId,
    coa_report_id: coa.id,
    ip_address: getClientIP(),
    user_agent: getUserAgent(),
    success: true
  })

  return signedUrl.signedUrl;
}
```

## Usage Examples

### 1. Upload CoA HTML File (Server Action)

```typescript
// src/app/actions/coa.ts
import { createClient } from '@/lib/supabase/server'
import crypto from 'crypto'

export async function uploadCoAHtml(
  sampleId: string,
  htmlContent: string,
  version: number
) {
  const supabase = await createClient()

  // Generate file path
  const timestamp = new Date().toISOString()
  const filePath = `${sampleId}/${version}-${timestamp}.html`

  // Generate SHA-256 hash
  const hash = crypto
    .createHash('sha256')
    .update(htmlContent)
    .digest('hex')

  // Upload to storage
  const { error: uploadError } = await supabase
    .storage
    .from('coa-reports')
    .upload(filePath, htmlContent, {
      contentType: 'text/html',
      upsert: false  // Prevent overwriting
    })

  if (uploadError) {
    // Log failed status
    await supabase.from('coa_reports').insert({
      sample_id: sampleId,
      file_path: filePath,
      file_hash: '',
      version,
      status: 'failed',
      error_message: uploadError.message
    })
    throw new Error(`Upload failed: ${uploadError.message}`)
  }

  // Update coa_reports with file_path and hash
  await supabase
    .from('coa_reports')
    .update({
      file_path: filePath,
      file_hash: hash,
      status: 'ready',
      generated_at: new Date().toISOString()
    })
    .eq('sample_id', sampleId)
    .eq('version', version)

  return { filePath, hash }
}
```

### 2. Generate Signed URL for Client Access

```typescript
// src/app/actions/coa.ts
export async function getCoADownloadUrl(
  sampleId: string,
  clientId: string,
  version?: number
) {
  const supabase = await createClient()

  // Fetch CoA report record
  let query = supabase
    .from('coa_reports')
    .select('id, file_path, file_hash, version')
    .eq('sample_id', sampleId)
    .eq('status', 'ready')
    .is('deleted_at', null)

  if (version) {
    query = query.eq('version', version)
  } else {
    // Get latest version
    query = query.order('version', { ascending: false }).limit(1)
  }

  const { data: coa, error } = await query.single()

  if (error || !coa) {
    throw new Error('CoA not found or not ready')
  }

  // Generate signed URL (1 hour expiry)
  const { data: signedUrlData, error: urlError } = await supabase
    .storage
    .from('coa-reports')
    .createSignedUrl(coa.file_path, 3600)  // 3600 seconds = 1 hour

  if (urlError || !signedUrlData) {
    throw new Error('Failed to generate download URL')
  }

  // Log access
  await supabase.from('coa_access_log').insert({
    client_id: clientId,
    sample_id: sampleId,
    coa_report_id: coa.id,
    ip_address: getClientIP(),
    user_agent: getUserAgent(),
    success: true
  })

  return {
    url: signedUrlData.signedUrl,
    version: coa.version,
    expiresAt: new Date(Date.now() + 3600 * 1000).toISOString()
  }
}
```

### 3. Retrieve CoA HTML for Staff Review

```typescript
// src/app/actions/coa.ts
export async function getCoAHtmlContent(sampleId: string, version?: number) {
  const supabase = await createClient()

  // Get file path from database
  let query = supabase
    .from('coa_reports')
    .select('file_path, file_hash, version')
    .eq('sample_id', sampleId)
    .eq('status', 'ready')
    .is('deleted_at', null)

  if (version) {
    query = query.eq('version', version)
  } else {
    query = query.order('version', { ascending: false }).limit(1)
  }

  const { data: coa, error } = await query.single()

  if (error || !coa) {
    throw new Error('CoA not found')
  }

  // Download file from storage
  const { data: fileData, error: downloadError } = await supabase
    .storage
    .from('coa-reports')
    .download(coa.file_path)

  if (downloadError || !fileData) {
    throw new Error('Failed to download CoA file')
  }

  // Convert blob to text
  const htmlContent = await fileData.text()

  // Verify file hash
  const computedHash = crypto
    .createHash('sha256')
    .update(htmlContent)
    .digest('hex')

  if (computedHash !== coa.file_hash) {
    throw new Error('File integrity check failed: hash mismatch')
  }

  return {
    html: htmlContent,
    version: coa.version,
    hash: coa.file_hash
  }
}
```
